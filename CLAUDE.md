# lowrezjam

## Code style

Do not write comments in source files. This applies to everyone working in this
repository, and to every source file (`.gd`, `.gdshader`, `.gdshaderinc`).

- No explanatory comments, no section banners, no `## ` doc comments, no
  commented-out code.
- Make the code self-explanatory instead: descriptive names for variables,
  constants and functions, and small functions that do one thing.
- Anything that genuinely needs prose belongs outside the source — in this file,
  in a commit message, or in a design document.
